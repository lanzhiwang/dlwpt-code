### 一、详细解释 DDP 的含义与核心原理

#### 1. 什么是 DDP (DistributedDataParallel)?

DDP 是 PyTorch 提供的一种`多进程`数据并行(Data Parallelism)实现.

* 数据并行(Data Parallel) 的含义是: 在每一个 GPU 上都复制一份`完整`的模型副本, 但将 Batch size 的训练数据切分(Split)给不同的 GPU.

* 每个 GPU 独立完成各自数据的前向传播(Forward)和反向传播(Backward), 计算出局部梯度(Local Gradients).

* 在反向传播过程中, DDP 会自动触发 AllReduce 通信操作, 将所有 GPU 上的梯度进行`求平均`同步, 最后每个 GPU 上的 Optimizer 使用完全相同的平均梯度更新本地的模型参数, 保证所有卡上的模型参数时刻保持一致.

#### 2. DDP 的核心设计与优势(对比旧版的 DataParallel / DP)

在 PyTorch 中, 曾经还有一个 `torch.nn.DataParallel`(DP), 但现在已经基本被废弃, DDP 具备以下压倒性优势:

1. 多进程架构(Multi-Process)而非单进程多线程:

   * DP: 基于单进程多线程, 受限于 Python 的 GIL(Global Interpreter Lock), 性能瓶颈极高, 且只能单机多卡.

   * DDP: 为每个 GPU 创建一个独立的 Python 进程, 彻底规避了 GIL 锁竞争; 同时原生支持多机多卡扩展.

2. 计算与通信重叠(Overlap Computation and Communication):

   * DDP 会将模型参数按逆序(反向传播的顺序)划分为多个 Bucket(桶).

   * 当反向传播计算完某个 Bucket 内参数的梯度时, DDP 立即在后台异步发起 AllReduce 通信同步梯度, 而此时 GPU 正在继续计算前面层(早先网络层)的梯度. 这种重叠显著掩盖了网络通信开销.

3. 高效的 C++ 通信底座(c10d):

   * DDP 底层由 PyTorch 的 C++ 分布式库 `c10d` 驱动, 能够充分调用硬件加速库(如 NVIDIA 的 NCCL, AMD 的 RCCL, CPU 的 Gloo).

#### 3. 核心概念名词解释

* World Size(全局进程总数/总卡数): 整个分布式集群中参与训练的总进程数. 例如 2 台机器, 每台 4 张卡, `world_size = 8`.

* Rank(全局进程 ID): 当前进程在所有 `world_size` 中的唯一标识, 编号从 `0` 到 `world_size - 1`. 通常 Rank 0 为 Master 节点.

* Local Rank(本地进程 ID): 当前进程在单台机器/节点内的 GPU 编号(例如某台 8 卡机器上的 0~7).

* Backend(通信后端): 底层节点间的通信协议库:

  * NCCL: NVIDIA GPU 训练的标准且最快的后端(强烈推荐 GPU 训练使用).

  * Gloo: CPU 训练或 Windows/macOS 上的跨平台调试后端.

  * MPI: 高性能计算集群常用的后端.

### 二、代码详细注释与机制解析

下面是对你提供的示例代码进行逐行详细注释, 并说明为什么这么写:

```python
import torch
import torch.distributed as dist
import torch.multiprocessing as mp
import torch.nn as nn
import torch.optim as optim
import os
from torch.nn.parallel import DistributedDataParallel as DDP


# 分布式训练的具体执行函数
# mp.spawn 会自动将当前的进程 ID (rank) 作为第一个参数隐式传递给该函数
def example(rank, world_size):
    # -------------------------------------------------------------
    # 1. 初始化分布式进程组 (Process Group)
    # -------------------------------------------------------------
    # dist.init_process_group 是连接所有分布式进程的关键.
    # "gloo": 指定通信后端(如果是 CUDA GPU 训练, 通常建议换成 "nccl").
    # rank: 当前进程的唯一标识(0, 1, ..., world_size-1).
    # world_size: 总进程数.
    # 为什么这么写: 所有进程需要通过此方法感知彼此, 建立 socket 通信通道.
    dist.init_process_group("gloo", rank=rank, world_size=world_size)

    # -------------------------------------------------------------
    # 2. 创建模型并将其移动到当前进程绑定的设备/GPU 上
    # -------------------------------------------------------------
    # model.to(rank) 在 CUDA 环境下等价于 .to(f'cuda:{rank}'), 将模型部署到特定的 GPU 上.
    # 注意: 示例这里用的是 CPU/Gloo 环境. 如果是在 GPU 上, 一般建议使用 local_rank 来定位卡.
    model = nn.Linear(10, 10).to(rank)

    # -------------------------------------------------------------
    # 3. 将模型包装为 DistributedDataParallel 模型
    # -------------------------------------------------------------
    # device_ids=[rank]: 告诉 DDP 该进程的模型部署在哪张卡上.
    # 内部动作: DDP 在构造时会把 Rank 0 的模型参数广播(Broadcast)给所有其他 Rank,
    # 确保所有进程中的模型初始权重完全一致; 同时注册 Hook 监听反向传播梯度.
    ddp_model = DDP(model, device_ids=[rank])

    # -------------------------------------------------------------
    # 4. 定义损失函数与优化器
    # -------------------------------------------------------------
    loss_fn = nn.MSELoss()
    # 注意: 优化器传入的是 ddp_model.parameters(), 实际上和 model.parameters() 共享内存.
    optimizer = optim.SGD(ddp_model.parameters(), lr=0.001)

    # -------------------------------------------------------------
    # 5. 前向传播与反向传播(训练循环内)
    # -------------------------------------------------------------
    # 生成随机输入数据并送入对应的 GPU/设备.
    # 在实际应用中, 数据应该由 DistributedSampler 进行分片, 保证每个 rank 拿到的 Batch 数据不同.
    outputs = ddp_model(torch.randn(20, 10).to(rank))
    labels = torch.randn(20, 10).to(rank)

    # 计算损失
    loss = loss_fn(outputs, labels)

    # 核心步骤: 执行反向传播!
    # 为什么这么写: 在 loss.backward() 执行期间, DDP 注册的 C++ Hook 会被触发,
    # 自动在后台进行跨进程的 AllReduce 操作, 将所有卡计算出的梯度求平均.
    loss.backward()

    # -------------------------------------------------------------
    # 6. 参数更新
    # -------------------------------------------------------------
    # 为什么直接 step 即可?
    # 因为上一步 backward() 完成后, 所有进程模型参数的 grad 已经被同步为全局平均梯度.
    # 因此每个进程独立执行 optimizer.step() 后, 更新后的模型权重依然保持完全一致!
    optimizer.step()

    # (补充最佳实践)训练完成后应当销毁进程组释放资源:
    # dist.destroy_process_group()


def main():
    world_size = 2  # 模拟使用 2 个进程(如果是 GPU 训练, 即 2 张 GPU 卡)

    # -------------------------------------------------------------
    # 使用 torch.multiprocessing.spawn 来启动多进程
    # -------------------------------------------------------------
    # mp.spawn 作用: 帮我们自动创建 world_size 个进程, 并各自运行 example 函数.
    # - example: 要在各个子进程中调用的目标函数.
    # - args=(world_size,): 额外传递给 example 的参数元组(注意 rank 是自动作为第一个参数传进去的).
    # - nprocs=world_size: 产生的进程数量.
    # - join=True: 主进程会阻塞等待, 直到所有的子进程执行完毕.
    mp.spawn(example, args=(world_size,), nprocs=world_size, join=True)


if __name__ == "__main__":
    # -------------------------------------------------------------
    # 设置主节点(Master Node)环境变量
    # -------------------------------------------------------------
    # MASTER_ADDR: 主节点的 IP 地址, 这里是单机环境, 设置为 localhost.
    # MASTER_PORT: 主节点开放的空闲端口, 用于进程间初始握手(Handshake).
    # 为什么这么写: dist.init_process_group 默认使用 "env://" 初始化模式,
    # 需要依赖这两个环境变量找到寻址入口.
    os.environ["MASTER_ADDR"] = "localhost"
    os.environ["MASTER_PORT"] = "29500"

    main()

```

# torchrun_demo.py
import torch
import torch.distributed as dist
import torch.nn as nn
import torch.optim as optim
import os
from torch.nn.parallel import DistributedDataParallel as DDP


def main():
    # 1. torchrun 会自动注入环境变量 LOCAL_RANK, RANK, WORLD_SIZE
    local_rank = int(os.environ["LOCAL_RANK"])
    global_rank = int(os.environ["RANK"])
    world_size = int(os.environ["WORLD_SIZE"])

    # 2. 设置设备并初始化通信组(针对 GPU 推荐 NCCL)
    torch.cuda.set_device(local_rank)
    dist.init_process_group(backend="nccl")

    # 3. 创建模型并移动到对应的 local_rank 卡上
    model = nn.Linear(10, 10).to(local_rank)
    ddp_model = DDP(model, device_ids=[local_rank])

    loss_fn = nn.MSELoss()
    optimizer = optim.SGD(ddp_model.parameters(), lr=0.001)

    # 4. 训练流程
    inputs = torch.randn(20, 10).to(local_rank)
    labels = torch.randn(20, 10).to(local_rank)

    outputs = ddp_model(inputs)
    loss = loss_fn(outputs, labels)

    loss.backward()  # 自动进行 AllReduce 梯度同步
    optimizer.step()

    print(f"[Rank {global_rank}] Training step finished successfully.")

    dist.destroy_process_group()


if __name__ == "__main__":
    main()

Q: 假设我现在有 1 台机器, 机器上有 8 张 GPU, 现在我想模拟`单机多卡 DDP`, 使用标准的 Python 命令执行训练脚本, 模型本身使用 `nn.Linear`, 数据也随机生成, 请输出完整的训练脚本, 包括模型保存和最后的资源回收, 并且说明如何运行脚本

下面为你提供一份完整的、可直接运行的单机 8 卡 GPU 训练脚本.

本脚本基于 `torch.multiprocessing.spawn` 编写, 使用标准的 `python` 命令即可直接触发 8 卡 DDP 并行训练. 脚本中包含了数据分布式分片(DistributedSampler)、通信组初始化、模型包装、仅在 Rank 0 上保存模型以及最后的资源清理等全套标准流程.

### 一、完整的 Python 训练脚本 (`ddp_8gpu_train.py`)

```python
import os
import torch
import torch.distributed as dist
import torch.multiprocessing as mp
import torch.nn as nn
import torch.optim as optim
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, Dataset
from torch.utils.data.distributed import DistributedSampler


# -------------------------------------------------------------------
# 1. 定义随机数据集
# -------------------------------------------------------------------
class RandomDataset(Dataset):

    def __init__(self, size, length):
        self.len = length
        self.data = torch.randn(length, size)
        self.labels = torch.randn(length, size)

    def __getitem__(self, index):
        return self.data[index], self.labels[index]

    def __len__(self):
        return self.len


# -------------------------------------------------------------------
# 2. 定义基于 nn.Linear 的简单模型
# -------------------------------------------------------------------
class SimpleModel(nn.Module):

    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)

    def forward(self, x):
        return self.linear(x)


# -------------------------------------------------------------------
# 3. 每个 GPU 进程执行的训练函数
# -------------------------------------------------------------------
def train_fn(rank, world_size):
    """
    rank: 当前进程的 GPU 编号 (0 ~ 7)
    world_size: 总 GPU 数 (8)
    """

    # --- A. 初始化 GPU 设备与分布式进程组 ---
    # 强制将当前进程绑定到对应的 GPU 卡上
    torch.cuda.set_device(rank)

    # 初始化 NCCL 通信后端(GPU 训练官方推荐通信库)
    dist.init_process_group(
        backend="nccl", init_method="env://", rank=rank, world_size=world_size
    )

    print(f"[Process Rank {rank}] 成功绑定到 GPU: {rank}")

    # --- B. 创建模型并包装为 DDP ---
    model = SimpleModel(in_features=10, out_features=10).to(rank)

    # device_ids=[rank]: 明确指定 DDP 监听当前进程绑定的哪张 GPU
    ddp_model = DDP(model, device_ids=[rank])

    criterion = nn.MSELoss()
    optimizer = optim.SGD(ddp_model.parameters(), lr=0.01)

    # --- C. 准备分布式数据 (DistributedSampler) ---
    dataset = RandomDataset(size=10, length=1600)  # 总共 1600 条随机数据

    # DistributedSampler 负责把 1600 条数据切分为 8 份, 每张卡拿到 200 条不同的数据
    sampler = DistributedSampler(
        dataset, num_replicas=world_size, rank=rank, shuffle=True
    )

    # 注意: 使用了 sampler 后, DataLoader 的 shuffle 必须为 False! 打乱逻辑移交给了 Sampler.
    dataloader = DataLoader(dataset, batch_size=32, sampler=sampler)

    # --- D. 模型训练循环 ---
    epochs = 3
    for epoch in range(epochs):
        # 必须在每个 epoch 开始时设置 set_epoch, 以保证各 Epoch 数据随机打乱的 Seed 发生变化
        sampler.set_epoch(epoch)

        total_loss = 0.0
        for step, (inputs, labels) in enumerate(dataloader):
            # 将数据推送到当前进程对应的 GPU 显存中
            inputs = inputs.to(rank)
            labels = labels.to(rank)

            # 前向传播
            outputs = ddp_model(inputs)
            loss = criterion(outputs, labels)

            # 反向传播 (DDP 会在此步骤自动触发跨 GPU 梯度的 AllReduce 同步)
            optimizer.zero_grad()
            loss.backward()

            # 梯度更新
            optimizer.step()

            total_loss += loss.item()

        avg_loss = total_loss / len(dataloader)

        # 最佳实践: 日志信息只在 Rank 0 上打印, 避免 8 张卡重复刷屏
        if rank == 0:
            print(f"--> Epoch [{epoch+1}/{epochs}] Finished, Avg Loss: {avg_loss:.4f}")

    # --- E. 模型保存 (Checkpoint Saving) ---
    # 强制让所有进程同步到此处, 确保训练完全结束
    dist.barrier()

    # 最佳实践: 只在 Rank 0 上执行保存文件操作, 防止多进程同时写一个文件导致损坏
    if rank == 0:
        checkpoint_path = "linear_ddp_model.pth"
        # 关键技巧: 保存 ddp_model.module.state_dict(), 剔除 DDP 自动添加的 'module.' 前缀
        # 这样保存出的文件可以在日后被非 DDP 的单卡模型直接加载!
        torch.save(ddp_model.module.state_dict(), checkpoint_path)
        print(f"[Rank 0] 模型权重已成功保存至: {checkpoint_path}")

    # --- F. 资源清理与回收 ---
    # 再次同步, 保证 Rank 0 保存完成后, 所有进程一起销毁进程组
    dist.barrier()
    dist.destroy_process_group()
    print(f"[Process Rank {rank}] 进程组已销毁, 分布式通信资源已释放.")


# -------------------------------------------------------------------
# 4. 主入口函数
# -------------------------------------------------------------------
def main():
    world_size = 8  # 设置使用的 GPU 卡数

    # 1. 检查当前机器 GPU 数量是否满足 8 张
    available_gpus = torch.cuda.device_count()
    if available_gpus < world_size:
        print(
            f"错误: 脚本配置需要 {world_size} 张 GPU, 但系统只检测到 {available_gpus} 张!"
        )
        return

    print(f"检测到系统可用 GPU 数量: {available_gpus}, 准备启动 8 卡 DDP 模拟训练...")

    # 2. 配置主节点通信环境变量
    os.environ["MASTER_ADDR"] = "localhost"  # 单机训练使用 localhost
    os.environ["MASTER_PORT"] = "29500"  # 空闲通信端口

    # 3. 使用 mp.spawn 派生 8 个子进程
    # mp.spawn 会自动为 8 个子进程注入 rank 参数 (0, 1, 2, ..., 7) 作为 train_fn 的第一个参数
    mp.spawn(train_fn, args=(world_size,), nprocs=world_size, join=True)


if __name__ == "__main__":
    main()

```

### 二、关键实现细节解析(为何要这么写?)

1. 为什么用 `DistributedSampler`?

   在数据并行中, 如果每张卡都训练相同的 Batch 数据, 就失去了多卡的意义. `DistributedSampler` 会将 1600 条数据集平均切分成 8 份, 确保每个 GPU 在一个 Epoch 内训练的是 200 条互不重复的数据.

2. 为什么调用 `sampler.set_epoch(epoch)`?

   如果不设置 `set_epoch`, 每个 Epoch 数据打乱(Shuffle)的随机数种子都是相同的, 会导致每个 Epoch 数据的送入顺序完全一致.

3. 为什么保存模型要用 `ddp_model.module.state_dict()`?

   被 DDP 包装后的模型, 参数名字前面都会被自动加上 `module.` 前缀(例如 `module.linear.weight`). 如果不加 `.module` 直接保存, 后续用普通的单卡 `SimpleModel` 加载时会出现 `Missing key(s) in state_dict` 的错误.

4. 资源回收的核心: `dist.barrier()` 与 `dist.destroy_process_group()`

   * `dist.barrier()` 相当于一个栅栏(同步点), 保证 8 个进程都运行到此处才继续向下执行.

   * `dist.destroy_process_group()` 用于及时关闭 C++ 底层的 NCCL Socket 端口与显存句柄, 防止程序结束后显存泄露或端口被持续占用.

Q: 假设我现在有 2 台机器, 每台机器上有 8 张 GPU, 现在我想模拟`多机多卡 DDP`, 使用标准的 Python 命令执行训练脚本, 模型本身使用 `nn.Linear`, 数据也随机生成, 请输出完整的训练脚本, 包括模型保存和最后的资源回收, 并且说明如何运行脚本

跨越到多机多卡(Multi-Node Multi-GPU)环境后, DDP 的核心计算逻辑没有变, 但网络通信与进程标识(Rank)发生了关键变化:

1. `world_size`(总进程数): $2 \text{ 台机器} \times 8 \text{ 张 GPU} = 16$.

2. 进程 ID 分裂为两种:

   * `local_rank`(本地卡号): 每台机器内部 0~7.

   * `global_rank`(全局卡号): 全集群 0~15. 计算公式为 `global_rank = node_rank * gpus_per_node + local_rank`.

3. 网络寻址(Master Node): 必须指定 Node 0(主节点)的真实局域网 IP 地址, 使得 Node 1 可以通过网络连上 Node 0 握手.

下面为你提供使用标准 Python 命令(结合 `argparse` 和 `mp.spawn`)实现 2 机 16 卡模拟训练的完整脚本与运行指南.

### 一、完整多机多卡训练脚本 (`multi_node_ddp.py`)

```python
import argparse
import os
import torch
import torch.distributed as dist
import torch.multiprocessing as mp
import torch.nn as nn
import torch.optim as optim
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, Dataset
from torch.utils.data.distributed import DistributedSampler


# -------------------------------------------------------------------
# 1. 随机数据集
# -------------------------------------------------------------------
class RandomDataset(Dataset):

    def __init__(self, size, length):
        self.len = length
        self.data = torch.randn(length, size)
        self.labels = torch.randn(length, size)

    def __getitem__(self, index):
        return self.data[index], self.labels[index]

    def __len__(self):
        return self.len


# -------------------------------------------------------------------
# 2. 简单的线性模型
# -------------------------------------------------------------------
class SimpleModel(nn.Module):

    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)

    def forward(self, x):
        return self.linear(x)


# -------------------------------------------------------------------
# 3. 训练函数(每个 GPU 进程单独执行)
# -------------------------------------------------------------------
def train_fn(
    local_rank, gpus_per_node, node_rank, world_size, master_addr, master_port
):
    """
    local_rank: 当前节点内的 GPU 编号 (0~7)
    gpus_per_node: 每台机器的 GPU 数量 (8)
    node_rank: 当前机器的节点编号 (0 或 1)
    world_size: 全局总卡数 (16)
    master_addr:
    master_port:
    """

    # 1. 计算全局进程 ID (Global Rank)
    # Node 0 的卡: 0~7, Node 1 的卡: 8~15
    global_rank = node_rank * gpus_per_node + local_rank

    # 2. 设置分布式环境变量
    os.environ["MASTER_ADDR"] = master_addr
    os.environ["MASTER_PORT"] = str(master_port)

    # 3. 绑定 GPU 设备并初始化跨机器通信组
    torch.cuda.set_device(local_rank)

    # init_process_group 会通过 TCP 协议连接 master_addr 上的主节点
    dist.init_process_group(
        backend="nccl", init_method="env://", rank=global_rank, world_size=world_size
    )

    print(
        f"[Node {node_rank}] [Local Rank {local_rank}] -> 全局 [Global Rank {global_rank}] 初始化成功!"
    )

    # 4. 创建模型并分配到本地 GPU
    model = SimpleModel(in_features=10, out_features=10).to(local_rank)
    ddp_model = DDP(model, device_ids=[local_rank])

    criterion = nn.MSELoss()
    optimizer = optim.SGD(ddp_model.parameters(), lr=0.01)

    # 5. 分布式数据分片(按照全局 16 个进程平分数据集)
    dataset = RandomDataset(size=10, length=3200)  # 3200 条数据, 16 卡平分, 每卡 200 条
    sampler = DistributedSampler(
        dataset, num_replicas=world_size, rank=global_rank, shuffle=True
    )
    dataloader = DataLoader(dataset, batch_size=32, sampler=sampler)

    # 6. 训练循环
    epochs = 3
    for epoch in range(epochs):
        sampler.set_epoch(epoch)
        total_loss = 0.0

        for step, (inputs, labels) in enumerate(dataloader):
            inputs = inputs.to(local_rank)
            labels = labels.to(local_rank)

            outputs = ddp_model(inputs)
            loss = criterion(outputs, labels)

            optimizer.zero_grad()
            loss.backward()  # DDP 跨 2 台机器、16 张卡自动做跨网 AllReduce 梯度求平均!
            optimizer.step()

            total_loss += loss.item()

        avg_loss = total_loss / len(dataloader)

        # 仅在集群真正的"绝对主卡"(Global Rank 0)上打印训练日志
        if global_rank == 0:
            print(f"--> Epoch [{epoch+1}/{epochs}] Finished, Avg Loss: {avg_loss:.4f}")

    # 7. 栅栏同步: 确保 2 台机器 16 张卡全部训练完毕
    dist.barrier()

    # 8. 模型保存: 仅在 Global Rank 0 (Node 0 的 GPU 0) 上保存权重文件
    if global_rank == 0:
        checkpoint_path = "multi_node_linear_ddp.pth"
        torch.save(ddp_model.module.state_dict(), checkpoint_path)
        print(f"\n[Global Rank 0] 全局模型权重已成功保存至: {checkpoint_path}")

    # 9. 资源回收
    dist.barrier()
    dist.destroy_process_group()
    print(f"[Global Rank {global_rank}] 资源回收完毕, 已安全退出.")


# -------------------------------------------------------------------
# 4. 主入口(处理命令行参数与进程派生)
# -------------------------------------------------------------------
def main():
    parser = argparse.ArgumentParser(description="2 机 16 卡 DDP 多机训练模拟脚本")
    parser.add_argument(
        "--master_addr",
        type=str,
        required=True,
        help="Node 0 (主节点) 的局域网 IP 地址",
    )
    parser.add_argument("--master_port", type=int, default=29500, help="主节点通信端口")
    parser.add_argument("--num_nodes", type=int, default=2, help="参与训练的总机器数")
    parser.add_argument(
        "--gpus_per_node", type=int, default=8, help="每台机器上的 GPU 数"
    )
    parser.add_argument(
        "--node_rank",
        type=int,
        required=True,
        help="当前机器的编号 (Node 0 填 0, Node 1 填 1)",
    )

    args = parser.parse_args()

    # 计算全局总卡数 (World Size = 2 * 8 = 16)
    world_size = args.num_nodes * args.gpus_per_node

    print(
        f"================ 分布式多机集群配置 ================"
        f"\n 当前节点编号 (Node Rank) : {args.node_rank}"
        f"\n 集群节点总数 (Num Nodes) : {args.num_nodes}"
        f"\n 每节点 GPU 数 (GPUs/Node): {args.gpus_per_node}"
        f"\n 全局总卡数 (World Size)  : {world_size}"
        f"\n Master 主节点通信地址    : {args.master_addr}:{args.master_port}"
        f"\n=================================================="
    )

    # 检查本地设备
    if torch.cuda.device_count() < args.gpus_per_node:
        print(
            f"错误: 本机需要 {args.gpus_per_node} 张 GPU, 但仅检测到 {torch.cuda.device_count()} 张!"
        )
        return

    # 在当前机器上派生 8 个子进程(对应本机的 8 张 GPU)
    mp.spawn(
        train_fn,
        args=(
            args.gpus_per_node,
            args.node_rank,
            world_size,
            args.master_addr,
            args.master_port,
        ),
        nprocs=args.gpus_per_node,
        join=True,
    )


if __name__ == "__main__":
    main()

```

在生产环境和深度学习大模型训练中, `torchrun`(PyTorch Elastic)是官方强烈推荐的分布式启动工具.

与之前使用 `mp.spawn` 的脚本相比, 使用 `torchrun` 的脚本有以下显著区别:

1. 无需在代码中使用 `mp.spawn`: 代码本身变成一个标准的单进程入口函数, `torchrun` 会在外部自动拉起 8 个独立的进程来并行运行该脚本.

2. 无需手动设置 `MASTER_ADDR` 和 `MASTER_PORT`: `torchrun` 会自动在环境变量中注入 `RANK`、`LOCAL_RANK`、`WORLD_SIZE`、`MASTER_ADDR` 和 `MASTER_PORT`.

3. `dist.init_process_group` 无需传参: 直接调用 `dist.init_process_group(backend="nccl")`, PyTorch 会自动从环境变量中读取配置完成握手.

### 一、适配 `torchrun` 的完整训练脚本 (`torchrun_8gpu.py`)

```python
import os
import torch
import torch.distributed as dist
import torch.nn as nn
import torch.optim as optim
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, Dataset
from torch.utils.data.distributed import DistributedSampler


# -------------------------------------------------------------------
# 1. 随机数据集
# -------------------------------------------------------------------
class RandomDataset(Dataset):

    def __init__(self, size, length):
        self.len = length
        self.data = torch.randn(length, size)
        self.labels = torch.randn(length, size)

    def __getitem__(self, index):
        return self.data[index], self.labels[index]

    def __len__(self):
        return self.len


# -------------------------------------------------------------------
# 2. 简单的线性模型
# -------------------------------------------------------------------

    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)

    def forward(self, x):
        return self.linear(x)


# -------------------------------------------------------------------
# 3. 主训练流程(每个由 torchrun 拉起的进程独立执行 main 函数)
# -------------------------------------------------------------------
def main():
    # --- A. 从环境变量中获取 torchrun 自动注入的参数 ---
    # LOCAL_RANK: 当前进程在单台机器上的 GPU 编号 (0 ~ 7)
    # RANK: 当前进程在全局集群中的 ID (单机 8 卡下, RANK 等于 LOCAL_RANK, 均为 0 ~ 7)
    # WORLD_SIZE: 全局总卡数 (8)
    local_rank = int(os.environ["LOCAL_RANK"])
    global_rank = int(os.environ["RANK"])
    world_size = int(os.environ["WORLD_SIZE"])

    # 绑定当前进程到本地对应的 GPU
    torch.cuda.set_device(local_rank)

    # 初始化分布式进程组
    # 使用 torchrun 时, 不需要传入 rank、world_size 或 init_method, 它会自动解析环境变量!

    print(
        f"[Global Rank {global_rank} | Local Rank {local_rank}] 初始化成功, 绑定设备: GPU {local_rank}"
    )

    # --- B. 模型初始化与 DDP 包装 ---
    model = SimpleModel(in_features=10, out_features=10).to(local_rank)
    ddp_model = DDP(model, device_ids=[local_rank])

    criterion = nn.MSELoss()
    optimizer = optim.SGD(ddp_model.parameters(), lr=0.01)

    # --- C. 数据加载与分布式采样器 ---
    dataset = RandomDataset(size=10, length=1600)  # 1600 条数据, 8 卡平分, 每卡 200 条
    sampler = DistributedSampler(
        dataset, num_replicas=world_size, rank=global_rank, shuffle=True
    )
    dataloader = DataLoader(dataset, batch_size=32, sampler=sampler)

    # --- D. 训练循环 ---
    epochs = 3
    for epoch in range(epochs):
        sampler.set_epoch(epoch)
        total_loss = 0.0

        for step, (inputs, labels) in enumerate(dataloader):
            inputs = inputs.to(local_rank)
            labels = labels.to(local_rank)

            outputs = ddp_model(inputs)
            loss = criterion(outputs, labels)

            optimizer.zero_grad()
            loss.backward()  # DDP 自动跨卡做梯度 AllReduce 同步
            optimizer.step()

            total_loss += loss.item()

        avg_loss = total_loss / len(dataloader)

        # 仅在 Global Rank 0 上打印训练日志
        if global_rank == 0:
            print(f"--> Epoch [{epoch+1}/{epochs}] Finished, Avg Loss: {avg_loss:.4f}")

    # --- E. 栅栏同步与模型保存 ---
    dist.barrier()  # 等待所有 8 张卡训练完成

    # 仅在 Global Rank 0 上保存模型
    if global_rank == 0:
        checkpoint_path = "torchrun_linear_ddp.pth"
        # 保存 ddp_model.module.state_dict(), 剥离 'module.' 前缀
        torch.save(ddp_model.module.state_dict(), checkpoint_path)
        print(f"\n[Global Rank 0] 模型已成功保存至: {checkpoint_path}")

    # --- F. 资源回收 ---
    dist.barrier()
    dist.destroy_process_group()
    print(f"[Global Rank {global_rank}] 通信进程组已销毁, 资源回收完毕.")


if __name__ == "__main__":
    main()

```

Q: 假设我现在有 2 台机器, 每台机器上有 8 张 GPU, 现在我想模拟`多机多卡 DDP`, 使用 torchrun 执行训练脚本, 模型本身使用 `nn.Linear`, 数据也随机生成, 请输出完整的训练脚本, 包括模型保存和最后的资源回收, 并且说明如何运行脚本

使用 `torchrun` 进行多机多卡(Multi-Node Multi-GPU)训练, 最优雅的一点在于: 你的 Python 训练代码与单机多卡版本相比, 完全不需要做任何修改!

`torchrun` 彻底解耦了"训练逻辑"与"多机网络调度":

* Python 脚本: 只需继续从环境变量中读取 `LOCAL_RANK`、`RANK` 和 `WORLD_SIZE`.

* 多机调度: 全部交给命令行参数(如指定主节点 IP、总节点数 `--nnodes` 和当前节点编号 `--node_rank`)来完成.

下面是适用于 2 机 16 卡的完整训练脚本以及具体的启动指令.

---

### 一、完整的 Python 训练脚本 (`torchrun_multi_node.py`)

将以下代码保存为 `torchrun_multi_node.py`, 并确保同时复制保存到 2 台机器的相同路径下:

```python
import os
import torch
import torch.distributed as dist
import torch.nn as nn
import torch.optim as optim
from torch.nn.parallel import DistributedDataParallel as DDP
from torch.utils.data import DataLoader, Dataset
from torch.utils.data.distributed import DistributedSampler


# -------------------------------------------------------------------
# 1. 随机数据集
# -------------------------------------------------------------------
class RandomDataset(Dataset):

    def __init__(self, size, length):
        self.len = length
        self.data = torch.randn(length, size)
        self.labels = torch.randn(length, size)

    def __getitem__(self, index):
        return self.data[index], self.labels[index]

    def __len__(self):
        return self.len


# -------------------------------------------------------------------
# 2. 简单的线性模型
# -------------------------------------------------------------------
class SimpleModel(nn.Module):

    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)

    def forward(self, x):
        return self.linear(x)


# -------------------------------------------------------------------
# 3. 主训练流程
# -------------------------------------------------------------------
def main():
    # --- A. 获取 torchrun 从外部注入的环境变量 ---
    # LOCAL_RANK: 当前进程在[本机]上的 GPU 编号 (0 ~ 7)
    # RANK: 当前进程在[整个 2 机 16 卡集群]中的全局唯一编号 (0 ~ 15)
    # WORLD_SIZE: 全局总卡数 (16)
    local_rank = int(os.environ["LOCAL_RANK"])
    global_rank = int(os.environ["RANK"])
    world_size = int(os.environ["WORLD_SIZE"])

    # 1. 绑定当前进程到本地对应的 GPU 卡
    torch.cuda.set_device(local_rank)

    # 2. 初始化分布式通信组(由 torchrun 自动通过网络完成 2 台机器间的握手)
    dist.init_process_group(backend="nccl")

    print(
        f"[Node Rank / Global Rank {global_rank}] [Local Rank {local_rank}] 成功绑定设备: GPU {local_rank}"
    )

    # --- B. 模型初始化与 DDP 包装 ---
    model = SimpleModel(in_features=10, out_features=10).to(local_rank)
    ddp_model = DDP(model, device_ids=[local_rank])

    criterion = nn.MSELoss()
    optimizer = optim.SGD(ddp_model.parameters(), lr=0.01)

    # --- C. 数据加载与 16 卡分布式切片 ---
    dataset = RandomDataset(size=10, length=3200)  # 3200 条数据, 16 卡平分, 每卡 200 条
    sampler = DistributedSampler(
        dataset, num_replicas=world_size, rank=global_rank, shuffle=True
    )
    dataloader = DataLoader(dataset, batch_size=32, sampler=sampler)

    # --- D. 训练循环 ---
    epochs = 3
    for epoch in range(epochs):
        sampler.set_epoch(epoch)
        total_loss = 0.0

        for step, (inputs, labels) in enumerate(dataloader):
            inputs = inputs.to(local_rank)
            labels = labels.to(local_rank)

            outputs = ddp_model(inputs)
            loss = criterion(outputs, labels)

            optimizer.zero_grad()
            loss.backward()  # DDP 自动触发跨机器、跨 GPU 的跨网 AllReduce 梯度同步
            optimizer.step()

            total_loss += loss.item()

        avg_loss = total_loss / len(dataloader)

        # 仅在全集群绝对主节点(Global Rank 0, 即 Node 0 的 GPU 0)上打印日志
        if global_rank == 0:
            print(f"--> Epoch [{epoch+1}/{epochs}] Finished, Avg Loss: {avg_loss:.4f}")

    # --- E. 栅栏同步与模型保存 ---
    dist.barrier()  # 确保所有 2 台机器的 16 张卡都已完成训练

    # 仅在 Global Rank 0 上保存模型权重
    if global_rank == 0:
        checkpoint_path = "multi_node_torchrun_model.pth"
        # 保存 ddp_model.module.state_dict(), 剥离 'module.' 前缀
        torch.save(ddp_model.module.state_dict(), checkpoint_path)
        print(f"\n[Global Rank 0] 全局模型已成功保存至: {checkpoint_path}")

    # --- F. 资源回收 ---
    dist.barrier()
    dist.destroy_process_group()
    print(f"[Global Rank {global_rank}] 通信进程组已销毁, 资源回收完毕.")


if __name__ == "__main__":
    main()

```

### 二、如何使用 `torchrun` 运行脚本

为了在两台机器上运行该脚本, 你需要打开 2 个终端分别连接到 Node 0 和 Node 1.

#### 前提环境检查

* 查明 Node 0(主节点) 的局域网 IP 地址(例如: `192.168.1.100`).

* 确保 Node 0 开放了 `29500` 端口, 且 Node 1 可以连通 Node 0(通过 `ping 192.168.1.100` 验证).

---

#### 方法 1: 标准经典命令行模式(推荐, 最直观)

在 Node 0 (主节点) 终端执行:

```bash
torchrun \
  --nnodes=2 \
  --nproc_per_node=8 \
  --node_rank=0 \
  --master_addr=192.168.1.100 \
  --master_port=29500 \
  torchrun_multi_node.py
```

在 Node 1 (从节点) 终端执行:

```bash
torchrun \
  --nnodes=2 \
  --nproc_per_node=8 \
  --node_rank=1 \
  --master_addr=192.168.1.100 \
  --master_port=29500 \
  torchrun_multi_node.py
```

> 参数说明:
> * `--nnodes=2`: 总节点数(机器数)为 2.
> * `--nproc_per_node=8`: 每台机器启动 8 个进程(对应 8 张 GPU).
> * `--node_rank=0` / `1`: 指明当前机器是第几台机器(主节点填 0, 从节点填 1).
> * `--master_addr`: 主节点(Node 0)的 IP 地址.
> * `--master_port`: 主节点的通信端口(默认 29500).
>

---

#### 方法 2: C10D Rendezvous 动态寻址模式(PyTorch 弹性调度模式)

如果你希望两台机器执行完全相同的命令, 可以使用 `rdzv` 语法(无需手动区分 `--node_rank`):

在 Node 0 和 Node 1 终端同时输入完全相同的指令:

```bash
torchrun \
  --nnodes=2 \
  --nproc_per_node=8 \
  --rdzv_id=my_training_job_100 \
  --rdzv_backend=c10d \
  --rdzv_endpoint=192.168.1.100:29500 \
  torchrun_multi_node.py
```

> 原理: `c10d` 寻址服务会根据进入连接的先后顺序, 自动给每台机器分配 `node_rank`.
>

### 四、多机跨网通信排错建议

1. 显式指定通信网卡(非常重要):

   如果机器上有多个网卡(如虚拟网卡、Docker 网卡或 InfiniBand 网卡), NCCL 可能走错网卡导致卡死. 可以通过环境变量指定绑定的网卡(如 `eth0` 或 `ens33`):

   ```bash
   NCCL_SOCKET_IFNAME=eth0 torchrun --nnodes=2 --nproc_per_node=8 ... torchrun_multi_node.py
   ```

2. 启用调试日志:

   如果连接不通, 可以在命令前加入 `NCCL_DEBUG=INFO` 打印底层连接建立日志:

   ```bash
   NCCL_DEBUG=INFO torchrun --nnodes=2 --nproc_per_node=8 ... torchrun_multi_node.py
   ```
